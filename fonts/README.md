# Шрифты

## Runtti SP Bold (встроен)
Авторы: Juuso Haimilahti, Sasha Pavljenko. Лицензия: SIL Open Font License 1.1 (текст в `OFL-RunttiSP.txt`).
Файл `RunttiSP-Bold.otf` распространяется без изменений. Используется для заголовков, штампов, вкладок, подписей и цифр.

## Свои шрифты
Положите файл `type.woff2`, `head.woff2` или `hand.woff2` (также .woff, .ttf, .otf) в эту папку и выберите пункт
«Свой файл» в настройках системы (Настройки игры → Настроить параметры → Нуар d20).
Проверьте, что лицензия шрифта разрешает его раздачу игрокам через браузер.
