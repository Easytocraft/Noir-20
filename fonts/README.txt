Шрифт «Special Elite» (машинопись, лицензия SIL OFL) придаёт листу вид настоящего досье.
1. Скачайте SpecialElite-Regular.ttf: https://fonts.google.com/specimen/Special+Elite
2. Положите файл в эту папку (fonts/SpecialElite-Regular.ttf).
Без файла система использует Courier New / American Typewriter — всё работает, просто выглядит проще.
