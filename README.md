# Нуар d20: Серый Порт — система для Foundry VTT v13 (0.4.7)

Ролевая нуарная система на d20. Лист персонажа оформлен как досье из картонной папки: фото со скрепкой, машинописная бумага, штампы.

## Установка
**Через Foundry:** Game Systems → Install System → Manifest URL:
`https://github.com/Easytocraft/Noir-20/releases/latest/download/system.json`

**Вручную:** скачайте `noir-d20.zip` из последнего релиза и распакуйте в `Data/systems/noir-d20/` (имя папки должно совпадать с `id`, иначе система не загрузится). При установке из репозитория клонируйте его так: `git clone https://github.com/Easytocraft/Noir-20 noir-d20`.

Затем создайте мир с этой системой.
При первом запуске GM автоматически создаются компендиумы (классы, подклассы, умения, приёмы, расы, происхождения, снаряжение).
Повторно: `game.noir.seed({force:true})` в консоли (очищает и пересоздаёт компендиумы системы).

## Правила в двух словах
- **Шесть характеристик:** Сила, Ловкость, Интеллект, Телосложение, Удача, Харизма. Значение сразу модификатор (от −3 до +5). Наведите курсор на характеристику, чтобы увидеть, за что она отвечает.
- **Проверка:** d20 + характеристика против сложности мастера. Клик по названию — бросок. Shift — преимущество, Ctrl — помеха. Навыков нет: мастер называет характеристику.
- **Защита как в Daggerheart:** Уклонение (10 + Ловкость + поправки), три ступени урона (Незначительный, Средний, Тяжёлый). Ступень определяет, сколько ран отмечается: 1, 2 или 3.
- **Раны:** 6 + Телосложение (+1 за каждые 3 уровня) плюс поправки класса и расы. Все раны отмечены — герой выбыл. Раны на листе показаны патронами (целый патрон — раны нет, гильза — рана).
- **Стресс:** запас 6 + Удача. Умения отмечают Стресс; Порок, сигареты и виски его снимают. Заполненный Стресс — срыв: проверки с помехой. Стресс — сигареты (окурок — отмеченный).
- **Кураж и Цинизм:** ползунок от −5 до +5. Кураж (+): потратьте 1 пункт, и следующая проверка идёт с преимуществом. Цинизм (−): потратьте 1 пункт, чтобы снять 1 Стресс. Сдвигает мастер.
- **Классы (9):** Гангстер, Вышибала, Лекарь, Оккультист, Шоумен, Сыщик, Взломщик, Водила, Наёмник. Каждый даёт одну особенность и пул из 6 способностей: на 1 уровне берутся 2, на 3, 5, 7 и 9 уровнях ещё по одной.
- **Расы (15):** Человек, Демон, Голиаф, Эльф, Муррены, Раттены, Орк, Дворф, Гоблин, Лилипут, Авианы, Гнолл, Тритон, Огр, Драконид. У каждой по 2 особенности. Смешанная родословная: две расы, из каждой берётся одна особенность.
- **Происхождения (10):** Правопорядок, Трущобы, Богема, Докарь, Мафиози, Консилум, Кочевник, Армейский солдат, Шабаш, Шпана. У каждого особенность, стартовые предметы и баксы.
- **Создание:** новый персонаж — 0 уровня. Кнопка **«Прокачаться»** (только у мастера) открывает окно «Создание персонажа»: класс и две способности, раса (или две), происхождение, характеристики, личность, снаряжение. Дальше она же даёт повышение уровня, когда заполнена шкала опыта (её тоже видит только мастер).
- **Опыт** мастер отмечает за сцены, Мотив и Порок, не за бои. Уровней 10. Нечётные уровни с 3-го требуют «цену роста»: Шрам, Долг или Враг. На 4 и 8 уровнях выбирается приём или +1 к двум характеристикам.

## Разработка
- `npm test` — проверка данных, ссылок, локализации и формул (без Foundry).
- `npm run bump -- 0.4.2` — повысить версию (или `patch`): обновляет `system.json`, `package.json` и ссылку `download`, добавляет заготовку в журнал изменений.
- `npm run packs` — собрать компендиумы в LevelDB и прописать `packs` в `system.json` (нужен `npm install`).
- Без собранных паков система сама создаёт мировые компендиумы при первом запуске.

## Картинки
Все иконки нарисованы для системы (векторные SVG, `assets/icons/`) и распространяются на тех же условиях, что и система. Чтобы заменить картинку на свою, положите файл рядом и поменяйте путь `img` в соответствующем файле `data/*.json`, затем выполните `game.noir.seed({force:true})` (или `npm run packs`). Либо просто замените SVG файлом с тем же именем.
