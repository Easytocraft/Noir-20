# Нуар d20: Серый Порт — система для Foundry VTT v13 (0.4.0)

Установка: скопируйте папку `noir-d20` в `Data/systems/`, создайте мир с этой системой.
При первом запуске GM автоматически создаются компендиумы (классы, умения, расы, происхождения, снаряжение).
Повторно: `game.noir.seed({force:true})` в консоли (дублирует контент в непустых компендиумах).

Правила в двух словах: d20 + мод + мастерство против КД/СЛ; шесть характеристик; 16 навыков;
Нерв (мод. МДР + 8 + уровень) — ресурс умений; Жар 0–5 — внимание полиции/банд; валюта — баксы.
Shift при броске — преимущество (крит при уроне), Ctrl — помеха.

## Разработка
- `npm test` — проверка данных, ссылок, локализации и формул (без Foundry).
- `npm run packs` — собрать компендиумы в LevelDB и прописать `packs` в `system.json` (нужен `npm install`).
- Без собранных паков система сама создаёт мировые компендиумы при первом запуске.
