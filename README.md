# Нуар d20: Серый Порт — система для Foundry VTT v13 (0.4.3)

Ролевая нуарная система на d20. Лист персонажа оформлен как досье из картонной папки: фото со скрепкой, машинописная бумага, штампы.

## Установка
**Через Foundry:** Game Systems → Install System → Manifest URL:
`https://github.com/Easytocraft/Noir-20/releases/latest/download/system.json`

**Вручную:** скачайте `noir-d20.zip` из последнего релиза и распакуйте в `Data/systems/noir-d20/` (имя папки должно совпадать с `id`, иначе система не загрузится). При установке из репозитория клонируйте его так: `git clone https://github.com/Easytocraft/Noir-20 noir-d20`.

Затем создайте мир с этой системой.
При первом запуске GM автоматически создаются компендиумы (классы, подклассы, умения, приёмы, расы, происхождения, снаряжение).
Повторно: `game.noir.seed({force:true})` в консоли (очищает и пересоздаёт компендиумы системы).

## Правила в двух словах
- **Шесть характеристик:** Сила, Ловкость, Интеллект, Телосложение, Удача, Харизма. Значение — сразу модификатор (от −3 до +5). Наведите курсор на характеристику, чтобы увидеть, за что она отвечает.
- **Проверка:** d20 + характеристика против сложности мастера. Клик по названию характеристики — бросок. Shift — преимущество, Ctrl — помеха. Навыков нет: мастер называет характеристику.
- **Защита как в Daggerheart:** Уклонение (10 + Ловкость + поправки), три ступени урона (Незначительный, Средний, Тяжёлый). Ступень определяет, сколько ран отмечается: 1, 2 или 3.
- **Раны** вместо хитов: 6 + Телосложение (+1 за каждые 3 уровня). Когда все раны отмечены — герой выбыл из строя.
- **Стресс:** запас 6 + Удача. Умения отмечают Стресс; Порок, сигареты и виски его снимают. Когда все отметки заполнены — **срыв**: проверки с помехой, пока Стресс не снят.
- **Кураж и Цинизм:** ползунок от −5 до +5, сдвигает мастер: к Куражу — за риск ради других, к Цинизму — за выгоду и равнодушие. Кураж (+): потратьте 1 пункт (сдвиньте к нулю), и следующая проверка идёт с преимуществом. Цинизм (−): потратьте 1 пункт, чтобы снять 1 Стресс. Правила видны во всплывающей подсказке над ползунком.
- **Создание:** новый персонаж — 0 уровня. Кнопка **«Прокачаться»** есть только у мастера: она открывает мастер создания (раса, класс, происхождение, характеристики), а дальше даёт повышение уровня, когда заполнена шкала опыта. Шкалу опыта тоже видит только мастер.
- **Опыт** мастер отмечает за сцены, Мотив и Порок, не за бои. Уровней 10. Нечётные уровни с 3-го требуют «цену роста»: Шрам, Долг или Враг.
- **Расы:** Человек, Эльф, Дворф, Гоблин, Крысолюд, Котари, Демон, Голиаф, Лилипут.

## Разработка
- `npm test` — проверка данных, ссылок, локализации и формул (без Foundry).
- `npm run bump -- 0.4.2` — повысить версию (или `patch`): обновляет `system.json`, `package.json` и ссылку `download`, добавляет заготовку в журнал изменений.
- `npm run packs` — собрать компендиумы в LevelDB и прописать `packs` в `system.json` (нужен `npm install`).
- Без собранных паков система сама создаёт мировые компендиумы при первом запуске.
