# Журнал изменений

## 0.4.0 — Стабилизация
- Проверки без Foundry: `npm test` (данные, ссылки, локализация, формулы КД/мастерства/Нерва).
- Исправлено: зависимость листа предмета от хелпера `or`; загрузка данных теперь через `getRoute` (работает с префиксом маршрута); старый уровень при повышении хранится в модуле, а не в options; откат при удалении предмета не падает, если актор уже удалён.
- Компендиумы: сборка в LevelDB (`npm run packs`), приоритет готовых паков системы над автосозданием в мире.
- Лицензия MIT, шаблон релиза GitHub, `package.json`.

## 0.3.0

## 0.2.0
